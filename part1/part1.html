Task 0. Responsive Typography

Font sizes change with screen width

Resize the browser window. On mobile the text is small, on tablet it is medium, and on desktop it is the largest. Media queries make this possible by applying different CSS rules at different screen widths.

Readable text is the foundation of responsive design: users should never need to zoom to read a page on a phone.
